# RFN01-136 Gitの変更ブロック

確認用ビルドをテスト専用の `LOCALAPPDATA` で起動する。一時リポジトリをWorkspaceに登録し、日本語と空白のあるテキストファイルの先頭行と末尾行を編集する。二つの変更の間に同じ行を十六行以上置く。

1. Git RepositoryのWIPでChangesのファイルを選び、「Gitの変更ブロックを確認…」を開く。Gitの差分が二つのブロックになり、未保存の内容を含まない旨が読めることを確認する。
2. 下のブロックをStageする。Staged Changesの差分が末尾行だけになり、Changesの差分が先頭行だけになることを確認する。
3. Staged Changesで同じファイルのブロックをUnstageする。Changesに二つの変更が戻り、ディスク上の内容が操作前のままであることを確認する。
4. ブロック画面を開いた後にTerminalで同じファイルを変更し、古いブロックの釦を押す。再選択が案内され、インデックスが変わらないことを確認する。
