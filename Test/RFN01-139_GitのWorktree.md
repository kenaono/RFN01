# RFN01-139 GitのWorktree

試験用のリポジトリをWorkspaceに登録し、コミットを作成する。確認用ビルドはテスト専用のプロファイルで起動する。

1. Git RepositoryからWorktree一覧を開く。パス、ブランチ、現在の作業先を確認する。Ctrl+Shift+Pのコマンドパレットからも一覧を開く。
2. 作成欄で親フォルダ、新しいフォルダ名、新しいブランチ名を指定する。作成後に2行が表示され、Workspaceにはまだ追加されていないことを確認する。既存のフォルダと元のWorktree内への作成は拒否されることを確認する。
3. 作成した行を開き、Workspace追加の確認でキャンセルすると元の作業先と登録内容が残ることを確認する。改めて追加して開き、Git ChangesとGit Repositoryの対象が揃うことを確認する。
4. 同名ファイルを両方のWorktreeで開き、一方の文書を未保存にする。もう一方でStage・Commitを行い、GitのindexとHEAD、編集中の文書に影響が及ばないことを確認する。
5. 一覧から元の作業先へ戻り、登録の確認が再度出ず、元のコミットメッセージの下書きが戻ることを確認する。
