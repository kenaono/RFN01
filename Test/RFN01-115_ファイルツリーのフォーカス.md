# RFN01-115 ファイルツリーのフォーカス

確認版をテスト用設定で起動する。作業フォルダに `notes/one.md` と `notes/two.md` を置き、最初は無題のTABを表示する。

| 操作 | 期待する結果 |
| --- | --- |
| Explorerの絞り込み欄をクリックし、Tab、↓、→、↓を順に押す | `notes` が展開され、`one.md` が選択される |
| Enterを押す | `one.md` が開き、ツリーの選択枠が残る。無題のTABの本文は操作前と同じ |
| 続けてDeleteを押し、確認をEscで閉じる | `one.md` の削除確認が出る。閉じるとツリーに戻る |
| `two.md` を1回クリックし、F2を押す | `two.md` が開き、その名前の変更画面が出る |
| 名前の変更画面をEscで閉じ、もう一度Escを押す | 最初のEscでツリーに戻り、次のEscで本文に移る |
