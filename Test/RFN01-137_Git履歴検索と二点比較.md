# RFN01-137 Git履歴検索と二点比較

Windowsで確認版をテスト専用の `LOCALAPPDATA` で起動する。初期のコミットに日本語と空白を含むファイルを作り、その後で200件以上のコミットを用意する。比較用のブランチを作り、片側でファイルを名前変更し、両側で内容を別々に変更する。

1. Git Repositoryの「履歴検索」を開き、初期表示に含まれないコミットをメッセージで探す。作者、SHAの接頭辞、ルートからのパスでも同じコミットを探す。
2. 検索結果を選び、コミットの詳細、変更ファイル、差分が開けることを確認する。
3. コミットの詳細かブランチの右クリックで比較元を指定し、別のコミットかブランチで「比較元との差分」を選ぶ。両端のSHA、名前変更を含む変更一覧、左右比較の内容を `git diff <比較元> <比較先>` と照合する。
4. 比較元を選んだ後に外部Gitでそのブランチを動かし、比較元のSHAが選択時のままであることを確認する。
5. ブランチの右クリックメニューを開いたまま、外部Gitでそのブランチを動かして別のブランチも追加する。更新後に比較元を設定し、メニューを開いた時点のSHAを使うことを確認する。
6. Ctrl+Shift+Pから履歴検索を開く。検索欄にフォーカスがある状態で再びパレットを開き、コミットグラフに戻る操作が出ることを確認する。コミットの詳細を表示して、比較元の設定と二点比較もパレットから実行する。
