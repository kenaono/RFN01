# RFN01-140 Gitリポジトリ一覧

1. 2つのWorkspaceに同じGitフォルダ、別パスの同名Clone、非Gitフォルダを登録する。登録済みの試験用フォルダを移動して、確認できない登録も1つ用意する。
2. File・Git Changes・Ctrl+Shift+Pの「リポジトリ一覧…」から同じ画面を開く。同じ作業ツリーが一行で、同名Cloneはパスの異なる行で表示されることを確認する。非Gitフォルダは除かれ、確認できない登録には理由が出る。
3. 名前・ブランチ・Workspaceで絞り込み、「現在のWorkspace」と「すべてのWorkspace」を切り替える。↑／↓で行を移動し、Escで元の画面に戻れることを確認する。
4. 別Workspaceの行をEnterで開く。未保存文書があれば既存の切り替え確認が出ること、キャンセルすると元のWorkspaceと一覧が残ることを確認する。切り替え後はGit ChangesとGit Repositoryの対象を確認する。
5. Workspaceを開いていない状態でも一覧を開く。表示倍率を上げ、選択行と現在の作業先を見分けられること、長いパスを選択行の詳細で読めることを確認する。
