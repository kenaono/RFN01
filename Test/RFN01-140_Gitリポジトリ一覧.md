# RFN01-140 Gitリポジトリ一覧

1. 2つのWorkspaceに同じGitフォルダを登録し、片方には別パスの同名Clone、もう片方には別のGitフォルダを登録する。非Gitフォルダと、登録後に移動した確認できないフォルダも用意する。
2. 複数の作業ツリーがあるWorkspaceで文書を開き、GitボタンとCtrl+Shift+Gから左ペインの一覧を開く。文書タブと本文が見えたまま、行を選ぶと同じペインにGit Changesが出ることを確認する。1件だけのWorkspaceではGit Changesが直接開く。
3. File・Git Changesの見出し・コマンドパレットの「リポジトリ一覧…」から同じ一覧を開く。同じ作業ツリーは一行にまとまり、同名Cloneはパスで見分けられる。非Gitフォルダは除かれ、確認できない行を選ぶと理由が出る。
4. 名前・パス・ブランチ・Workspaceで絞り込む。↑／↓とEnterで行を選び、Escで一覧を閉じる。表示倍率を上げても所属Workspaceを見分けられ、長いパスは行のツールチップで読めることを確認する。
5. 別Workspaceにだけ属する行を選ぶ。切り替え先と現在のタブを閉じることが、未保存の有無にかかわらず表示される。キャンセルで一覧と元のタブが残り、切り替えに同意すると選んだリポジトリのGit Changesに進む。未保存時は保存・破棄・キャンセルを確認する。
6. Workspaceを開いていない状態で、開ける行がすべて通常表示されることを確認する。1か所に所属する行を選ぶと所属WorkspaceとGit Changesが開く。複数に所属する行は開くWorkspaceを選べる。
7. 開けない行を選び、理由の下の「登録解除…」を押す。確認に所属と登録パス、ディスク上のファイルとGit履歴が残ることが表示される。キャンセルで登録が残り、確認後は一覧から消える。所属なしの行と複数所属の行で試し、後者は選んだ所属だけ外れることを確認する。
