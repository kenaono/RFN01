# RFN01-116 Windows実画面のシナリオ

AIがComputer Useで確認する。操作する前に対象ウィンドウを特定し、画面が変わるたびに観察してから次に進む。普段のセッションを使わず、対象のビルドをテスト専用の `LOCALAPPDATA` で起動する。テスト用の作業フォルダに `日本語の文書.md` をUTF-8で用意し、本文を `# 確認用` とする。必要なIMEやプリンターがすでに利用できる環境で実施する。

## W01 ファイルダイアログのキャンセルと日本語パス

1. 無題のTABを表示し、Ctrl+Oを押す。Windowsのファイルダイアログが開くことを確認する。
2. Escで閉じる。無題のTABに戻り、TABが増えていないことを確認する。
3. Ctrl+Oで開き直す。ファイル名欄に `日本語の文書.md` の絶対パスを入力し、開く。
4. ファイル名がTABに表示され、本文に `# 確認用` が見えることを確認する。

## W02 日本語IMEの変換とフォーカス復帰

1. 無題のTABを開き、本文にフォーカスを置く。日本語IMEが入力できる状態を確認する。
2. IMEに実際のキー入力を送り、「にほんご」を変換する。変換中の表示と候補が本文の近くに出ることを確認する。文字列の直接挿入はIME検証に使わない。
3. 候補を確定し、本文に確定した文字が1回だけ入ることを確認する。
4. Ctrl+Oでファイルダイアログを開き、Escで閉じる。本文に戻り、続けてIMEで入力できることを確認する。
5. テスト用の無題TABを保存せず閉じる。

## W03 印刷ダイアログをキャンセルしてプレビューへ戻る

1. `日本語の文書.md` を開き、メニューから印刷プレビューを表示する。本文とページが見えることを確認する。
2. プレビューの印刷ボタンを押す。Windowsの印刷ダイアログが表示されたら、キャンセルする。
3. 同じプレビューに戻ることを確認する。Escで閉じ、元の文書とTABに戻ることを確認する。
