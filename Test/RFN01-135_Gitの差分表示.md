# RFN01-135 Gitの差分表示

Windowsで確認用ビルドをテスト専用の `LOCALAPPDATA` で起動する。一時リポジトリをWorkspaceに登録し、`空白 を含む原稿.md` の2行をCommitする。1行目を編集してStageし、続いて2行目を編集する。

1. Git Changesの **Staged Changes** にあるファイル行の「差分を表示」を押す。左右の見出しがHEADとインデックスになり、1行目だけが変わっていることを確認する。
2. Escで閉じ、**Changes** 側の同じファイルの「差分を表示」を押す。インデックスと作業ツリーが比較され、2行目だけが変わっていることを確認する。
3. Git Repositoryの `// WIP` を開き、両方の行で同じ差分が出ることを確認する。通常幅の窓で比較元と「比較の画面で開く」が読めること、左右の内容と比較元が引き継がれ、Escで差分に戻ることも確認する。
4. Git Changesのファイル行をダブルクリックし、ファイルを開いて編集中の本文をHEADと比較できることを確認する。
